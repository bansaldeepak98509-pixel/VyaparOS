MASTER PROMPT — PREMIUM BILINGUAL BUSINESS MANAGEMENT APP

APP NAME

Create a premium Indian business management app called:

VyaparOS — Smart Business Manager

Tagline:
“Hisab bhi Smart, Business bhi Smart.”

The app must be designed for Indian shopkeepers, small businesses, wholesalers, retailers, distributors and family businesses.

---

1. CORE GOAL

Build a business management app that is:

- Premium
- Extremely fast
- Lightweight
- Mobile-first
- Offline-first
- Hindi + English bilingual
- Very easy for a non-technical shopkeeper
- Professional enough for a growing business
- Modern and polished
- Data-safe
- Extremely smooth on low-end Android phones

The product experience should feel significantly more polished and complete than traditional Bahi-Khata apps.

Do NOT simply copy OKCredit or any existing app.

Take inspiration from the usefulness of digital khata apps, but create a unique product, unique UI and unique workflow.

---

2. IMPORTANT DEVELOPMENT RULE

If an existing HTML/app file is provided:

UPGRADE THE EXISTING APP.

Do NOT unnecessarily rebuild it from scratch.

Preserve:

- Existing functionality
- Existing data
- Existing database
- Existing IndexedDB structure
- Existing screens
- Existing working features

Only modify architecture when necessary.

If database changes are required, create a safe migration system.

NEVER silently delete existing user data.

5. LIGHTWEIGHT REQUIREMENT

Performance is extremely important.

The app must:

- Load quickly
- Use minimal JavaScript
